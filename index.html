About the brush-timer-tidbits app

The channel owner uses a small private tool, brush-timer-tidbits, to upload episodes to the Brush Timer Tidbits YouTube channel, edit their titles, descriptions and thumbnails, and read the channel's own analytics. It uses YouTube API Services. It is not offered to anyone else.
